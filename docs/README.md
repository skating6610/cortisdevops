## 项目简介

cortisdevops 是一款面向企业场景的开源 DevOps 与自动化运维平台，聚焦多云资源管理、应用交付、任务编排、权限治理、配置管理和通知告警等核心能力。

平台采用前后端分离架构，前端基于 Vue 生态构建，后端基于 Python Tornado 服务体系，适合用于企业内部 DevOps 平台、运维自动化平台、CMDB 平台和云资源管理平台建设。

## 你可以用它做什么

- 建立统一的主机、云资源和业务拓扑管理入口
- 编排应用发布、脚本任务、审批流和审计流程
- 管理用户、角色、业务权限和访问控制策略
- 通过配置中心统一维护系统级配置
- 通过通知中心提升告警和流程消息触达效率
- 在 Docker Compose、Kubernetes 等环境中部署和扩展平台
